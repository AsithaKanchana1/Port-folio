# Hello World — Starting My Blog

Welcome to my personal blog! I'm **Asitha Kanchana**, a Software Engineering student at the Open University of Sri Lanka, and this is the first post on my new blog.

## Why I'm Starting a Blog

I've been learning and building things for a while now, and I realized I should start writing about it. Here's why:

- **To document my learning** — Writing helps me understand topics better
- **To share knowledge** — If something helped me, it might help someone else
- **To track my progress** — Looking back at old posts is a great way to see how far you've come
- **To improve my communication skills** — Technical writing is an important skill for any developer

## Hidden Sri Lanka — My First Real Project

One of my most meaningful projects so far is **Hidden Sri Lanka** — an Android app that helps users discover hidden travel spots in Sri Lanka based on their location.

It was built with:
- **Android Native** (Java)
- **Firebase** for backend and real-time data
- **Google Maps API** for location services

Working on it taught me so much about building production-level apps. I'll write a detailed post about it soon!
